# Agent integration alternatives

## Which products cover managed OAuth, embedded UI, Gmail and Outlook, tools, MCP, tenant isolation, and execution?

### Takeaway
Composio, Nango, Arcade, and Paragon can all replace Pipedream's managed-auth/tool layer, but they optimize for different things. Composio is the closest agent-first turnkey replacement; Nango offers the strongest code-first ownership and portability; Arcade is strongest on per-action authorization/governance; Paragon is a mature embedded-iPaaS choice but its commercial model is sales-led. Zapier has the largest catalog, but its MCP is currently centered on each user's Zapier account rather than a clean embedded multi-tenant product flow.

### Cited Findings
- Composio sessions are keyed by the application's stable `user_id`, scope toolkits/auth/connected accounts, support multiple accounts for one toolkit, generate Connect Links, and persist connections across later sessions; Composio handles redirects, token exchange, and refresh. A session can also expose a hosted MCP endpoint with the same user/tool/account scope. — [Composio sessions](https://docs.composio.dev/docs/how-composio-works); [Composio MCP sessions](https://docs.composio.dev/docs/sessions-via-mcp)
- Composio's authentication docs state that each user's accounts are isolated, credentials are encrypted and refreshed server-side, the app/model receives results rather than tokens, and raw provider endpoints can be reached through Proxy Execute when no predefined tool exists. — [Composio authentication](https://docs.composio.dev/docs/authentication)
- Composio advertises 1,500+ toolkits, including Gmail, and has a dedicated Outlook authorization/tool guide; its Connect MCP surface uses seven meta-tools for discovery, authorization, and parallel execution instead of loading the whole catalog into model context. — [Composio Connect](https://docs.composio.dev/docs/composio-connect); [Composio Outlook](https://docs.composio.dev/kb/guide/toolkits-outlook)
- Nango exposes one hosted MCP/tool surface with 7,000+ ready-made tools across 1,000+ APIs, while each connection belongs to one user or organization and each agent session explicitly limits connections, integrations, and tools. It supports encrypted credential storage, retries, rate-limit handling, logs, triggers, OpenTelemetry export, and self-hosting. — [Nango MCP and tools](https://nango.dev/platform/mcp/)
- Nango's public catalog explicitly lists Gmail and Outlook, and its hosted runtime MCP pins calls to an end user's connection through `connection-id` and `provider-config-key` headers; runtime and management MCP keys are deliberately separate. — [Nango integration catalog](https://nango.dev/api-integrations); [Nango agent integration guide](https://nango.dev/blog/how-to-build-ai-agent-integrations-using-the-nango-management-mcp)
- Arcade's runtime evaluates both user authorization and agent scope at action time, keeps credentials away from agents/MCP clients, handles refresh/rotation, and offers cloud, VPC, and air-gapped deployment options. Its open MIT-licensed `arcade-mcp` framework supports custom tools and generic OAuth2 providers. — [Arcade product](https://www.arcade.dev/product/); [Arcade MCP GitHub](https://github.com/ArcadeAI/arcade-mcp)
- Arcade has pre-built Gmail/Google authorization and an Outlook Mail toolkit with 30 tools. Important limitation: Arcade's Outlook Mail documentation says the MCP server requires a Microsoft work or school account and does not support personal `@outlook.com` or `@hotmail.com` accounts. — [Arcade Google auth](https://docs.arcade.dev/en/references/auth-providers/google); [Arcade Outlook Mail](https://docs.arcade.dev/en/resources/integrations/productivity/microsoft-outlook-mail)
- Paragon provides white-labeled embedded auth, fully managed OAuth, a user connection portal, and ActionKit through API or MCP. Its catalog includes Gmail and Microsoft Outlook, including mail search/read/send actions and triggers. — [Paragon ActionKit](https://www.useparagon.com/actionkit); [Paragon Gmail](https://www.useparagon.com/integrations/gmail); [Paragon Outlook](https://www.useparagon.com/integrations/outlook)
- Zapier MCP exposes 9,000+ apps and 40,000+ actions with credentials and rate limits handled by Zapier. However, the documented product model is a server created in a user's Zapier account for each named AI client; server sharing is a Team/Enterprise feature. Zapier's developer SDK is still beta. — [What is Zapier MCP](https://help.zapier.com/hc/en-us/articles/48308034391821-What-is-Zapier-MCP); [Zapier pricing](https://zapier.com/pricing)

### Inferences
- Composio maps most directly onto NoteStack's existing architecture: a stable NoteStack user/workspace ID becomes the provider user ID, Connect Links handle OAuth, and a session or MCP URL supplies curated tools. This should require less conceptual change than adopting a workflow-centric embedded iPaaS.
- Nango is better when NoteStack expects integrations to become a core product surface requiring custom code, syncs, webhooks, and provider-specific fixes. It is less of a pure “switch on a catalog” product and more of an integration runtime the team can shape.
- Arcade is attractive if NoteStack's differentiator becomes safe agent actions and enterprise policy enforcement, but its personal-Outlook limitation is a material mismatch for a broad consumer email product.
- Zapier should not be the first embedded provider choice until its SDK exits beta and its per-user embedded auth/tenancy contract and future pricing are stable.

### Gaps
- Vendors count apps, APIs, toolkits, actions, and tools differently, so catalog totals are not directly comparable.
- Public documentation does not provide comparable success-rate or latency benchmarks across the same Gmail/Outlook operations.

## What are the pricing, production-readiness, lock-in, extensibility, self-hosting, and security tradeoffs?

### Takeaway
Composio is dramatically cheaper on published entry pricing and includes unlimited connected accounts, but its hosted execution/runtime remains proprietary and zero-data-retention costs extra. Nango has the most legible user-based pricing and source-visible/self-hostable architecture, with an important Elastic License caveat. Arcade is open at the tool-framework layer but its managed engine is proprietary and relatively costly per action. Paragon looks production-ready and enterprise-oriented but does not publish a usable dollar price.

### Cited Findings
- Composio's current published plan includes 100,000 tool calls, 50,000 triggers, unlimited connected accounts, OAuth management, and basic white-labeling for $0; Pro is $29/month with usage credit, and ordinary overage is $0.0003/tool call. Advanced white-labeling is $0.30 per connection once, Proxy Execute adds $0.0002/call, and zero-data-retention adds $0.0001/tool call plus $0.0005/trigger. Enterprise adds KMS, SSO, SCIM, SLA, and dedicated support. — [Composio pricing](https://landing.composio.dev/pricing)
- Composio states SOC 2 Type II and ISO 27001 compliance, cloud/VPC/self-hosted deployment options, and that self-hosting/VPC are Enterprise arrangements. Hosted credentials and execution remain inside Composio's platform unless an enterprise deployment model is negotiated. — [Composio platform and security](https://landing.composio.dev/)
- Nango's Free plan allows 10 connections, 10 compute hours, and 10 GB egress monthly; pay-as-you-go is $50/month credit with $0.29/connection/month, $0.72/compute hour, and $0.50/GB. Enterprise offers commitment discounts, SLA, MSA, self-hosting, and BYOC; the page claims SOC 2 Type II, GDPR, HIPAA/BAA, RBAC, audit trails, and OTel export. — [Nango pricing](https://nango.dev/pricing)
- Nango's code is publicly inspectable and actively maintained, with roughly 12.5k GitHub stars and 1.4k forks reported in October 2026. But the repository uses Elastic License 2.0, which prohibits offering a substantial set of the software as a hosted/managed service and is not an OSI open-source license. — [Nango GitHub](https://github.com/NangoHQ); [Nango license](https://github.com/NangoHQ/nango/blob/master/LICENSE)
- Arcade's Free plan includes 2,000 tool calls/month. Team costs $25/month plus $0.01 per tool call. Enterprise adds VPC/air-gapped deployment, SSO, RBAC, audit logs, private registry, SLA support, and custom pricing. — [Arcade pricing](https://www.arcade.dev/pricing/)
- Arcade's tool/MCP framework is MIT-licensed and can run standalone, but managed user authorization, execution, and governance are Arcade Cloud/Enterprise runtime services. — [Arcade MCP framework](https://github.com/ArcadeAI/arcade-mcp); [Arcade developer platform](https://www.arcade.dev/developers/)
- Paragon's Pro and Enterprise tiers include unlimited integrations, managed auth, white-labeled/headless UI, ActionKit API/MCP, dev/staging/prod environments, SOC II/GDPR controls, and enterprise on-premise/single-tenant options, but the public page says “Get a quote” rather than listing prices or usage rates. — [Paragon pricing](https://www.useparagon.com/pricing)
- Zapier MCP has no separate price but each successful MCP tool call consumes two tasks from the user's existing Zapier allowance; failed calls are free. The SDK is free only while in beta and Zapier says it will notify users before pricing changes. — [Zapier MCP billing](https://help.zapier.com/hc/en-us/articles/45645738385805-How-Zapier-MCP-usage-works); [Zapier pricing](https://zapier.com/pricing)
- For comparison, Pipedream's current production plan starts at $99/month annually or $150 monthly, includes 100 external users and 10,000 credits, then charges $2/user and $0.012/credit; production use is unavailable on its free development tier. — [Pipedream pricing](https://pipedream.com/pricing)

### Inferences
- At NoteStack's early stage, Composio's free allowance and unlimited connections create the lowest-cost credible experiment; Pipedream's mandatory production base fee makes it harder to validate demand cheaply.
- Nango reduces long-term connector lock-in because integration functions are code and the runtime can be self-hosted, but calling it fully open source would be misleading under ELv2. Enterprise-only deployment features and operational burden still create lock-in/cost.
- Arcade's $0.01/call can be expensive for research workflows that fan out across many mailbox reads. Its value is policy/governance rather than lowest cost.
- Paragon is likely best suited after NoteStack has enterprise customers and procurement/security requirements that justify a sales-led contract.

### Gaps
- Composio's marketing pages contain inconsistent historical free-tier figures in older content; the dedicated current pricing page should be treated as authoritative at purchase time.
- Paragon does not publish dollar pricing, so no honest cost comparison is possible without a quote.
- No vendor publishes a complete export/migration guarantee for managed OAuth connections; changing providers generally requires users to reauthorize.

## Which two or three are actually stronger than Pipedream for NoteStack, and why?

### Takeaway
For NoteStack now: shortlist Composio first and Nango second. Keep Pipedream as the low-friction incumbent/baseline. Arcade is a conditional third choice for enterprise-grade agent authorization, while Paragon is a later enterprise option. None is universally “better”; each is stronger on a different decision axis.

### Cited Findings
- **Composio is stronger for a fast, agent-native launch:** it has explicit per-user sessions, dynamic tool discovery, hosted MCP endpoints, Connect Links, Gmail/Outlook support, user/account isolation, and a current free allowance of 100,000 calls with unlimited connected accounts. — [Composio sessions](https://docs.composio.dev/docs/how-composio-works); [Composio pricing](https://landing.composio.dev/pricing); [Composio Outlook](https://docs.composio.dev/kb/guide/toolkits-outlook)
- **Nango is stronger for control, custom integration code, and future sync/webhook needs:** it combines per-user auth, an embedded UI, tools, runtime MCP, proxy access, syncs, webhooks, OTel observability, self-hosting/BYOC, and published per-connection pricing. Gmail and Outlook are both in its catalog. — [Nango MCP and tools](https://nango.dev/platform/mcp/); [Nango pricing](https://nango.dev/pricing); [Nango catalog](https://nango.dev/api-integrations)
- **Arcade is stronger specifically for authorization and governance:** user and agent permissions are intersected per action, tokens are isolated from the model, and enterprise deployments can run in VPC/on-prem/air-gapped environments. It is not the default recommendation because personal Outlook accounts are unsupported and Team tool calls cost $0.01 each. — [Arcade product](https://www.arcade.dev/product/); [Arcade Outlook](https://docs.arcade.dev/en/resources/integrations/productivity/microsoft-outlook-mail); [Arcade pricing](https://www.arcade.dev/pricing/)
- **Pipedream remains stronger on breadth and immediate prebuilt coverage:** it currently advertises 3,000+ connectors and 10,000+ tools/triggers, managed auth, Connect SDK/API/MCP, and explicit Gmail and Microsoft Outlook MCP toolsets. — [Pipedream pricing](https://pipedream.com/pricing); [Pipedream Gmail](https://mcp.pipedream.com/app/gmail); [Pipedream Outlook](https://mcp.pipedream.com/app/microsoft_outlook)
- **Paragon is stronger for classic embedded-iPaaS depth:** it combines ActionKit MCP/API with white-labeled auth, asynchronous workflows, triggers, normalized schemas, and enterprise deployment/security options, but pricing is opaque. — [Paragon pricing](https://www.useparagon.com/pricing); [Paragon ActionKit](https://www.useparagon.com/actionkit)
- **Zapier is not currently stronger for NoteStack's embedded flow despite the broadest catalog:** each server belongs to a Zapier account/client configuration, successful calls consume two tasks, and the product SDK is still beta. — [Zapier MCP overview](https://help.zapier.com/hc/en-us/articles/48308034391821-What-is-Zapier-MCP); [Zapier MCP billing](https://help.zapier.com/hc/en-us/articles/45645738385805-How-Zapier-MCP-usage-works); [Zapier pricing](https://zapier.com/pricing)

### Inferences
- Recommended proof-of-concept sequence: test the same three operations (search recent mail, fetch a full message/thread, create a draft) with Composio and Nango using separate Gmail and Outlook test tenants. Measure tool schema quality, OAuth completion/reconnect behavior, latency, error clarity, and total calls. Keep Pipedream only if it wins enough of those tests to justify its higher entry cost.
- If NoteStack wants an integration marketplace soon, Nango's customizable code, syncs, webhooks, and proxy are strategically stronger. If it mainly wants agent actions now, Composio is the simplest swap.
- A provider abstraction in NoteStack should keep provider user ID, app slug, connected-account ID, tool name, and risk annotations separate. That reduces migration cost and prevents any vendor's tool names or account model from leaking into notebooks and chat history.

### Gaps
- A real bake-off is still required: vendor documentation cannot establish which Gmail/Outlook tools have the best schemas, pagination, attachment handling, delegated/shared mailbox behavior, or reliability for NoteStack's prompts.
- Google restricted-scope verification and Microsoft tenant-consent behavior can depend on whether NoteStack uses vendor-managed OAuth apps or brings its own; the exact production consent experience must be tested with each finalist.
