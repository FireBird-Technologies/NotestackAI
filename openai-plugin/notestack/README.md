# Notestack OpenAI plugin package

This directory is the source for the ZIP uploaded to the OpenAI Plugin Directory.

The public package intentionally contains only:

- `plugin.json` for listing, review, and publication metadata
- `mcp.json` for the hosted MCP endpoint
- public brand icons under `assets/`

Before submitting for review, add public privacy-policy and terms-of-service URLs in the OpenAI dashboard (or add
`privacyPolicyURL` and `termsOfServiceURL` to `extensions.com.openai.interface` after those pages exist). Add a reviewer
demo recording and test-account credentials in the secure dashboard fields. Credentials must never be added to this
package.
