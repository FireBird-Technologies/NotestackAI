# A job is taking long or failed
Syncing, topic mapping, audio, video, reports, infographics, quizzes, flashcards and Launch Kits run in the background. Check **Mission Control** for jobs in flight. Failed items in the **Library** have a retry button. Large archives take longer to sync.

# Upgrade prompt
An upgrade prompt appears when you reach a plan limit such as sources, indexed posts, audio minutes, video minutes, Launch Kits, reports or infographics. Limits reset monthly where they are monthly.

# Sharing a report fails
Check **Allow public report links** in **Settings** under **Privacy and email**. If it is off, nothing can be shared.

# Uploads
Supported file types are md, markdown, txt, html and pdf.

# Mobile
The marketing pages work on mobile. The main app is not yet optimised for small screens.

# Still stuck
If none of this helps, use the Talk to a human button in this chat and the team will email you back.
