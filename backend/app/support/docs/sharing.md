# Share a report or an infographic
1. Click **Share** on the report or infographic card, or on the report page.
2. Click **Create share link**.
3. Click **Copy link** and send it. **Open the page** previews it.
Anyone with the link can read it without an account. They cannot edit it. The page shows the report or infographic only: no source text, no quotes and no name.

# Show which sources were used
For a report, the checkbox **Show which sources were used** decides whether the public page lists the posts it was made from. It is on by default and you can change it any time.

# Stop sharing
Click **Share**, then **Stop sharing**. The link stops working for good. Sharing again makes a new link.

# Turn public links off for everyone
In **Settings** under **Privacy and email**, the option **Allow public report links** controls this. Turn it off and no report can be shared, and links you already made stop working. If Share says it is not allowed, check this setting.

# What can be shared
Only finished reports and infographics. Quizzes, flashcards and Mind Constellations cannot be shared by link, and there is no other way to give someone else a quiz or flashcard set. A quiz or flashcards can be added to an interactive report, and that report can be shared. A shared report can be downloaded as Markdown only by the owner.
