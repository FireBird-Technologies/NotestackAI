# Where it is
**Library** is in the left sidebar, between Sources and Launchpad. Its heading is "Everything you have made".

# Tabs
**All**, **Reports**, **Summaries**, **Quizzes**, **Flashcards**, **Mind Constellations**, **Infographics**, **Videos** and **Voices**. Each tab filters one list. Audio overviews and Launch Kits show under **All**. **Videos** and **Voices** open their own pages.

# On each card
Cards have the buttons that fit what they are: **Open report**, **Open summary**, **Start quiz**, **Study cards**, **Open**, **Share**, **Download**, **Retry** for a failed one and **Delete**. Generation runs in the background, so you can leave the page. If the list does not load, click **Try again**.
